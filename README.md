# 🖥️ Code Calibrate
### _Practice what you need. Build toward mastery._

Code Calibrate is a full-stack coding practice and learning platform inspired by language-learning applications such as Duolingo. Users can create accounts, follow structured learning paths, practice individual programming skills, and track their progress as they build mastery.

Rather than simply moving users through a predetermined course, Code Calibrate uses their practice history and performance to help determine which skills they should focus on next.

## ✨ Features

### While logged out

- Create an account
- Log in to an existing account
- View available learning paths
- View the skills covered by each learning path
- View available coding exercises

### While logged in

- Follow a learning path
- View skills included in a learning path
- Practice coding exercises
- Submit answers to exercises
- Receive feedback on submitted answers
- Track exercise attempts
- View mastery progress for individual skills
- View GitHub projects related to skills being practiced

### Learning and mastery

- Track correct and incorrect exercise attempts
- Calculate a mastery score for individual skills
- Track the number of questions attempted and answered correctly
- Record when a skill was last practiced
- Use performance history to guide future practice

### External integrations

- Retrieve coding exercises from external sources
- Connect relevant GitHub projects to programming skills
- Use GitHub project information as additional learning material

## 🎯 How Code Calibrate Works

Code Calibrate is built around the idea that completing a lesson does not necessarily mean a user has mastered the material.

Users practice individual programming skills through exercises. Their results are recorded and used to build a picture of their current mastery.

For example:

```text
Practice
   ↓
Submit Answer
   ↓
Record Result
   ↓
Update Skill Mastery
   ↓
Determine What to Practice Next
