# User Stories

> A user can create an account, select a Java learning path, complete coding problems, have their performance tracked against individual programming skills, receive personalized 
recommendations based on their performance, discover relevant GitHub projects, and access the completed application through a deployed production enviroment. 


- [ ] As a new user, I want to create an account so that learning progress can be saved.
- [ ] As a user, I want to securely log in so I can access my personal learning dashboard.
- [ ] As a user, I want my authenticated session to persist while using CodeCalibrate, avoiding repeatedly logging in.
- [ ] As a user, I want to select a programming learning path so I can work with a specific programming language. 
- [ ] As a user, I want to view the skills within my learning path so that I understand what concepts I'm attempting to master.
- [ ] As a user, I want to see my mastery for each skill so that I know which concepts I understand and which need more practice.
- [ ] As a user, I want CodeCalibrate to recommend an exercise based on my current skills so that I know what I should practice next. 
- [ ] As a user, I want CodeCalibrate to retrieve coding problems from an external source so that I have a variety of problems to practice.
- [ ] As a user, I want to complete a coding exercise so that I can practice specific programming concepts.
- [ ] As a user, I want to submit my answer and receive feedback so that I know whether I understand the problem.
- [ ] As a user, I want to see the result and explanation of my attempt so that I can understand what I got right or wrong.
- [ ] As a user, I want to see my recommended next exercise so that I can continue learning.
- [ ] As a user, I want CodeCalibrate to find GitHub projects related to my programming skills so that I can apply what I have learned to real-world code.
- [ ] As a user, I want to view information about recommended GitHub projects so that I can decide whether a project is appriopriate for my skill level.
- [ ] As a user, I want to open a recommended project on GitHub so that I can explore or work on it.
- [ ] As a user, I want to access CodeCalibrate through a deployed web application so that I can use it without running it locally. 
- [ ] As a user, I want authentication to work in the deployed application so that my account and progress remain secure.
- [ ] As a user, I want my learning progress and attempts to persist in the production database, so I don't lose my progress.

- [ ] As CodeCalibrate, I want to record exercise attempts so that their performance can be used to calculate skill mastery.
- [ ] As CodeCalibrate, I want to update a user's mastery based on their exercise performance so that their skill levels reflect their recent progress.
- [ ] As CodeCalibrate, I want to use a user's mastery and practice history to determine what they should practice next.
